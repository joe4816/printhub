PRINTHUB PROVISIONING

Endpoint Setup

Generate the auto-launch URL for one ChromeOS PrintHub endpoint. Endpoint IDs are routing identifiers, not secrets.

Auto-launch URL

Use the generated URL as the kiosk / auto-launch target. On first load, PrintHub stores the endpoint ID, label, and media preference locally so later launches can use the base URL.

What this does not configure

This page does not assign a physical printer, change Google Admin policy, enable silent printing, or create authentication credentials. Those remain separate deployment steps.
